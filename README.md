# 猜数字小游戏

## 一、项目简介

这是一个使用 Python 编写的简单猜数字小游戏。

程序会随机生成一个 1 到 100 之间的整数，玩家需要通过不断猜测，直到猜中正确答案。

## 二、运行环境

- Python 3

## 三、运行方法

在终端中进入存放 `guess_number.py` 的文件夹，然后执行：

```bash
python guess_number.py
```

## 四、游戏规则

1. 程序随机生成一个 1 到 100 之间的整数。
2. 玩家输入自己猜测的数字。
3. 如果猜大了，程序提示“大了”；如果猜小了，程序提示“小了”。
4. 猜中后，程序显示正确答案和猜测次数。
